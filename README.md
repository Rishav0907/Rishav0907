## 🚀 Selected Projects

### 1. Compressed Multi-Task Qwen3 for Code Intelligence
Fine-tuned and compressed Qwen3-0.6B for multiple code intelligence tasks using LoRA and WANDA pruning.

- Multi-task learning across code defect detection, clone detection, and code summarization.
- Applied structured experimentation with LoRA adapters and model merging.
- Evaluated performance degradation under different pruning levels.
- Maintained approximately 89% defect detection accuracy at 30% WANDA pruning.

### 2. Text-to-SQL with Fine-Tuned Phi-3
Built a schema-aware Text-to-SQL system using Phi-3 Mini and parameter-efficient fine-tuning.

- Fine-tuned using SQL instruction datasets.
- Implemented multi-turn schema-aware query generation.
- Integrated SQLGlot for SQL validation, normalization, and retry mechanisms.
- Achieved 94% exact-match accuracy and 100% syntactically valid SQL after validation and retry.

### 3. Hybrid Semantic Search Engine
Developed a hybrid information retrieval system combining sparse and dense retrieval.

- BM25 and FAISS-based dense retrieval.
- Used Reciprocal Rank Fusion (RRF) for result aggregation.
- Evaluated using NDCG@10 and MRR.
- Achieved 0.9356 NDCG@10 and 0.9167 MRR.

### 4. ADAS Model Evaluation & Fairness
Developed an evaluation pipeline for lane detection models under diverse environmental conditions.

- Evaluated open-source lane detection architectures.
- Used CARLA-based synthetic scenario generation.
- Investigated robustness across weather, lighting, and lane-marking variations.
- Explored fairness-oriented evaluation beyond conventional aggregate accuracy metrics.

### 5. Vision-Language-Action Model Evaluation
Exploring the evaluation of modern VLA models for autonomous driving.

- Evaluating reasoning and trajectory generation capabilities.
- Investigating reasoning-action inconsistencies.
- Exploring multimodal benchmarks and scenario-based evaluation.
- Working with models and frameworks in the autonomous driving ecosystem.
